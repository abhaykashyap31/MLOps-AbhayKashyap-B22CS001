\section{Q1: LoRA on ViT-S for CIFAR-100}
\subsection{Objective}
The goal was to finetune an ImageNet-pretrained ViT-S model on CIFAR-100 in two settings:
\begin{itemize}
    \item baseline head-only finetuning without LoRA,
    \item LoRA-based adaptation over multiple rank and alpha combinations with dropout fixed at 0.1.
\end{itemize}
The assignment also required train/validation metrics, test comparison tables, class-wise accuracy histograms, gradient-update plots on LoRA weights, Optuna tuning, and model publication.

\subsection{Implementation Summary}
The final Q1 pipeline uses the following design choices:
\begin{itemize}
    \item Base model: \texttt{vit\_small\_patch16\_224} from \texttt{timm}, pretrained on ImageNet.
    \item Dataset: CIFAR-100.
    \item Baseline: backbone frozen, classification head trainable.
    \item LoRA grid: ranks \{2,4,8\}, alpha \{2,4,8\}, dropout \(=0.1\).
    \item Data preprocessing: resize to \(224 \times 224\), CIFAR-100 normalization, random crop, and horizontal flip.
    \item Optimizer: AdamW.
    \item Scheduler: cosine annealing.
    \item Additional logging: LoRA gradient norms were recorded and plotted.
\end{itemize}

\subsection{Important Note on Q, K, V Injection}
The assignment asks for LoRA injection into the attention weights of \(Q\), \(K\), and \(V\). In the \texttt{timm} ViT implementation used here, these projections are exposed as a \textbf{single fused} linear layer named \texttt{qkv} rather than separate \texttt{q\_proj}, \texttt{k\_proj}, and \texttt{v\_proj} modules. Therefore, LoRA was applied to the fused \texttt{qkv} projection. This is the correct implementation choice for this codebase and is explicitly documented here to avoid ambiguity.

\subsection{Observations}
\begin{itemize}
    \item The baseline head-only finetuning reached a test accuracy of \(0.7791\).
    \item The best fixed-grid LoRA setting was \texttt{rank=4}, \texttt{alpha=8}, \texttt{dropout=0.1}, with test accuracy \(0.8778\).
    \item This is an absolute improvement of \(0.0987\) over the baseline.
    \item Several LoRA settings performed very similarly, which indicates that the method is robust over a modest hyperparameter range.
    \item The optional partial-freeze + LoRA run (\(0.8712\)) did not improve over the best fully frozen-backbone LoRA result.
    \item The Optuna-selected configuration trained in the final run achieved \(0.8510\), which was below the best manually enumerated grid result in this experiment set.
\end{itemize}

\section{Q2: Adversarial Attacks Using IBM ART}
\subsection{Objective}
This part has two components:
\begin{itemize}
    \item compare FGSM implemented from scratch versus FGSM from IBM ART on CIFAR-10 using a ResNet-18 classifier trained from scratch,
    \item train adversarial detectors on mixed clean/adversarial samples for PGD and BIM attacks using ResNet-34 based models.
\end{itemize}

\subsection{Implementation Summary}
The Q2 pipeline trains a clean ResNet-18 classifier, evaluates FGSM attacks over multiple epsilon values, and then trains two binary detectors:
\begin{itemize}
    \item PGD detector: clean vs PGD-adversarial,
    \item BIM detector: clean vs BIM-adversarial.
\end{itemize}
The script generates visual comparisons for FGSM scratch, FGSM ART, PGD, and BIM, and logs those artifacts to WandB together with image tables, metrics, and attack summaries. The current workspace snapshot contains an updated Q2 run log and the corresponding WandB links.

\subsection{Clean Classification Accuracy}
In the latest recorded run, the clean CIFAR-10 classifier reached a final test accuracy of \(\mathbf{0.8350}\), which satisfies the assignment requirement of at least \(0.72\).

\section{Conclusion}
This assignment demonstrates two complementary themes: parameter-efficient finetuning and robustness evaluation.
\begin{itemize}
    \item For Q1, LoRA substantially improved CIFAR-100 performance over baseline head-only finetuning, with the best result coming from \texttt{rank=4}, \texttt{alpha=8}.
    \item For Q2, the clean ResNet-18 classifier achieved strong performance, while adversarial robustness degraded with stronger FGSM perturbations as expected.
    \item The PGD and BIM detectors both met the minimum performance target.
\end{itemize}
