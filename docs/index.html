📌 Assignment Objective

The goal of this assignment is to perform a comprehensive experimental study on image classification using deep learning and classical machine learning models. The experiments focus on understanding the impact of different hyperparameters, optimizers, compute devices, and architectures on model accuracy, training time, and computational cost.

📊 Datasets Used

  • MNIST – Handwritten digit classification
  • FashionMNIST – Clothing image classification

🧠 Models Implemented

  • ResNet18
  • ResNet50
  • Support Vector Machine (SVM)

⚙️ Hyperparameters Explored

  • Batch Size: 16, 32
  • Learning Rates: 0.001, 0.0001
  • Optimizers: SGD, Adam
  • Epochs: 1, 2
  • Pin Memory: True, False
  • Device: CPU vs GPU

📈 Key Experimental Findings

  • Adam optimizer generally converged faster and achieved higher accuracy.
  • Lower learning rates performed better for deeper models like ResNet50.
  • Pin memory improved training performance when using GPU.
  • GPU significantly reduced training time compared to CPU.
  • RBF kernel outperformed polynomial kernels in SVM experiments.

🏆 Best Performing Configurations

The best performance on MNIST and FashionMNIST datasets was achieved using Adam optimizer with a learning rate of 0.0001 and batch size of 16. Detailed numerical results, accuracy tables, and training time comparisons are provided in the full report.
