Assignment Overview

This assignment focuses on image classification using MNIST and FashionMNIST datasets. Deep learning models such as ResNet18 and ResNet50 were trained with different hyperparameter configurations including batch size, learning rate, optimizer, epochs, and pin_memory settings.

Models Used

  • ResNet18
  • ResNet50
  • SVM (RBF and Polynomial Kernels)

Key Experiments

  • Effect of batch size and learning rate
  • Comparison between SGD and Adam optimizers
  • Impact of pin_memory on performance
  • CPU vs GPU training comparison
