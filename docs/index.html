🎯 Mission Objective

This assignment presents a comprehensive experimental study on image classification using deep learning and classical machine learning models. The experiments systematically analyze the impact of different hyperparameters, optimizers, compute devices, and architectures on model accuracy, training time, and computational cost across two benchmark datasets.

📊 Datasets Explored

MNIST

Handwritten digit classification dataset (70,000 grayscale images, 10 classes)

FashionMNIST

Clothing and fashion item classification (70,000 grayscale images, 10 classes)

🤖 Neural Architectures Deployed

  • ResNet18 – 18-layer residual network with skip connections
  • ResNet50 – Deeper 50-layer architecture for complex pattern recognition
  • Support Vector Machine (SVM) – Classical ML with RBF and polynomial kernels

🔬 Key Research Findings

Optimizer Performance

Adam optimizer consistently converged faster and achieved higher accuracy compared to SGD, especially with lower learning rates. Adam's adaptive learning rate proved crucial for deeper networks like ResNet50.

Learning Rate Impact

Lower learning rate (0.0001) performed significantly better for deeper models. ResNet50 showed dramatic improvement with LR 0.0001, while ResNet18 was more robust to LR variations.

Hardware Acceleration

GPU training reduced training time by ~60-70% compared to CPU. Pin memory optimization provided noticeable performance gains when using GPU acceleration.

SVM Kernel Analysis

RBF kernel significantly outperformed polynomial kernels across both datasets. Polynomial kernels with 'auto' gamma showed poor performance and excessive training times.

Batch Size Effects

Batch size 16 generally provided better accuracy than 32, especially for Adam optimizer. Smaller batches allowed more frequent weight updates, improving convergence.

Computational Cost

ResNet50 required 2.27× more FLOPs than ResNet18 (4.132 vs 1.824 GFLOPs) but provided marginal accuracy improvements on MNIST while showing better performance on FashionMNIST.

💡 Critical Insights

  • Optimizer Selection: Adam's adaptive learning rates make it superior for deep networks, while SGD requires careful learning rate tuning
  • Hardware Utilization: GPU acceleration is essential for practical deep learning workflows, reducing training time from hours to minutes
  • Kernel Selection in SVM: RBF kernel's ability to model non-linear boundaries makes it the preferred choice for image classification tasks
  • Regularization Trade-offs: Higher C values (C=10) in SVM improved accuracy but increased overfitting risk and training time
  • Dataset Complexity: FashionMNIST proved more challenging than MNIST, with all models showing 8-10% lower accuracy
  • Memory Optimization: Pin memory feature provided measurable improvements in GPU training throughput
